
# Base de Datos Ventas_Tech_DB - TechStore

## Descripción
Este proyecto contiene el script de creación y carga inicial de la base de datos `Ventas_Tech_DB` para la tienda de tecnología TechStore. El modelo sigue un diseño relacional normalizado (3NF) compuesto por las tablas `categorias`, `clientes`, `productos` y `ventas`.

## Requisitos
- SQL Server

## Instrucciones de Ejecución
1. Abrir el gestor de base de datos y conectarse al servidor.
2. Crear una nueva base de datos llamada `Ventas_Tech_DB` y seleccionarla.
3. Abrir el archivo `ventas_tech_db.sql`.
4. Ejecutar el script en su totalidad (`Execute` o `F5`).
5. El script se encargará de resetear las tablas existentes, crear la estructura con sus PK/FK, poblar los datos iniciales y ejecutar las consultas de validación.
